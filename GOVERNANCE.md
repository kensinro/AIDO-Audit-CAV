# CAV code governance

- Frozen results are append-only.
- Failure, HOLD, ABSTAIN, disagreement, trace defects, and denominator boundaries remain visible.
- No post-outcome denominator repair.
- No post-Gold score rewriting.
- Claim-ceiling safety is not correctness.
- Selective agreement is not overall accuracy.
- New benchmark/scoring/claim-ceiling logic requires a new version and explicit Human governance.
