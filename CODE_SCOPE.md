# Scope of this code

This is a reference/scoring implementation reconstructed from the frozen CAV schemas and Final-Locked metric definitions.

It **does**:
- validate output contracts;
- replay P2/P3/P4B-E metrics;
- verify hashes;
- lint selective-audit reporting.

It **does not**:
- recreate the blinded LLM semantic operator;
- infer missing source evidence;
- repair Gold labels;
- change a frozen denominator;
- convert abstention into correctness;
- claim scientific truth, causality, or clinical validity.
